# MissAV小助手

一个面向 MissAV/ThisAV 播放页的用户脚本。

当前脚本文件：

- `MissAV小助手.user.js`

## 功能

- 自动嗅探当前页面可用的 `m3u8`
- 默认选择可用的最高分辨率
- 支持手动切换分辨率
- 支持 `流式下载 TS`
- 支持 `浏览器下载`
- 支持自定义分片并发数，并自动保存设置
- 遇到 Cloudflare / 安全验证页时自动隐藏面板
- 保留基础播放增强与去干扰逻辑

## 安装

推荐环境：

- Chrome / Edge + Tampermonkey
- Firefox + Tampermonkey / Violentmonkey

安装方式：

1. 安装用户脚本管理器
2. 导入 `MissAV小助手.user.js`
3. 打开 MissAV/ThisAV 播放页使用

## 使用说明

### 分辨率

- 左侧分辨率按钮可直接切换
- `自动最高` 会自动选择当前可用的最高分辨率

### 下载

- `流式下载 TS`
  - 脚本会自动抓取分片、合并并交给浏览器下载
  - 下载文件名默认仅保留标题，不附加分辨率后缀
- `浏览器下载`
  - 直接打开最高画质 `m3u8`
  - 若浏览器安装了支持 HLS 的下载扩展，可由扩展接管

### 并发

- 面板右侧支持设置下载并发
- 当前可设范围：`1 - 16`
- 修改后会自动保存到本地

## 说明

- 脚本不能直接调用 Neat Download Manager 的右键菜单
- 若 NDM 或其它扩展没有接管 `m3u8`，`浏览器下载` 只会打开或下载播放列表
- `流式下载 TS` 走的是脚本内部分片拉取与合并逻辑，因此不会被 NDM 直接接管
